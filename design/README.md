## 🎯 设计概览

### 设计主题: **Aurora（极光）**
- **灵感**: 深空中的粉色极光 — 黑暗与霓虹的碰撞
- **关键词**: 年轻 · 活力 · 科技 · 音乐热情
- **Brand Anchor**: B 站经典粉 `#FB7299` — 保留品牌基因

### 色彩体系

```
Primary     #FB7299 · #FF8DB5  —— B站品牌粉（不变）
Secondary   #00D4FF            —— 霓虹蓝（科技感点缀）
Tertiary    #7C5CFC            —— 星空紫（渐变辅助）
Background  #07070f · #0a0a18  —— 深空底色
Surface     #0f0f23 · #161630  —— 浮层色（玻璃拟态）
Error       #FF5F57            —— 错误/删除
Success     #28C840            —— 成功状态
```

| 字体 | 用途 | 字重 |

## 🖥️ 界面设计要点

### 布局（维持 3 栏结构）
- **左侧（280px）**: 播放列表 — 全新的 grid 布局，每项缩略图带渐变背景
- **中间（1fr）**: 播放器占位区 — 内嵌 WebContentsView，黑色底
- **右侧（340px）**: 搜索 — 圆角搜索条，毛玻璃标签切换

### 底部播放栏（全新设计）
- **玻璃拟态**: `backdrop-filter: blur(24px)` 半透明毛玻璃效果
- **顶部霓虹线**: 粉色渐变细线作为视觉分割
- **渐变进度条**: 粉→紫 渐变色，悬浮时显示圆形拖拽手柄
- **控制按钮**: 播放键带粉色发光阴影

### 搜索卡片
- **圆角规范**: 12px (card) / 10px (button) / 8px (tag)
- **悬停效果**: 上浮 3px + 柔和阴影 + 缩放封面
- **添加按钮**: 渐显式十字按钮，添加后变粉底白勾

### 动效曲线
```css
--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);  /* 弹性 */
--ease-out: cubic-bezier(0, 0, 0.2, 1);              /* 标准退出 */
```

## 🧩 核心组件规范

| 组件 | 圆角 | 背景 | 交互反馈 |
|------|------|------|----------|
| 按钮 (Filled) | 12px | 粉紫渐变 | 上浮 2px + scale 1.02 |
| 按钮 (Outlined) | 12px | `var(--card)` | 背景变亮 |
| 按钮 (Tonal) | 12px | 粉 10% 透明 | 透明度提升 |
| 输入框 | 10px | `var(--card)` | Focus: 粉边框 + 光晕 |
| 卡片 | 12px | `var(--card)` | 上浮 3px + 阴影 |
| 标签/Tag | 8px | 各色 10% 透明 | 背景略微加深 |
| 滑块 | 4px 轨道 | `var(--border)` | 粉色滑块 + 发光 |
| 开关 | 11px | `var(--border)` | 粉色激活状态 |

## 📐 如何应用到项目中

1. **图标**: 选择你喜欢的图标编号 → 在 `build/` 中添加对应的 `.ico` 文件
2. **CSS Tokens**: 将 `design/index.html` 中的 `:root` 变量复制到 `src/renderer/style.css`
3. **组件样式**: 按需替换原有 CSS 类
4. **字体**: 在 `index.html` 中添加 Google Fonts 链接
